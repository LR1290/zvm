# ZVM R46.98 - Accessibility and legacy cleanup for Analytics

Base: main R46.97 (fbb33ea3). This is an offline test candidate, NOT a production release until CI and Chromium are green.

## What has changed
- Keyboard navigation for the two existing Laboratory tabs: Left, Right, Home and End. Tabs now have unique IDs, aria-controls, aria-labelledby, roving tabindex and associated tab panels. Selection remains instant and local, without triggering an API.
- The existing Laboratory button reports aria-expanded and aria-controls while keeping the same toggle function and no new network requests.
- The payment filters are labelled button groups with aria-pressed reflecting exactly one selected button per group. A polite live region reports visible rows after filtering/searching.
- UI mismatch fixed: the period filter previously showed "7d" selected with no period cutoff (all rows visible). The initial selected button is now "Todos", matching the original runtime behavior. Selecting 7d still applies the existing 7-day logic.
- Accessible skip link and focusable main for keyboard users, with a visible focus style.
- The 30-day revenue SVG is preserved and paired with a native HTML table of 30 days, revealing exact sales counts and revenues on demand. No Chart.js, external CDN, PDF or chart data pipeline changes.
- Explicit table captions, column headers and search label for Analytics tables. Chart display, data queries, export, commercial logic, real-vs-test partitions and irreversible purge guards remain.
- The peak-hour widget now uses the already calculated peakHour value, instead of two extra in-place sorts on the stats.byHour array. This avoids mutating server-side aggregate input during rendering.
- Stale purge preview responses are ignored after the selected deletion mode changes or the dialog closes. Existing preview/count/confirmation validation remains authoritative on the server.
