# ZVM R47.00 — Public Site Experience

Base: main R46.99 (aca567a754a036b992746a39e0e53ea5967ab027).
Scope: full public-experience consolidation for landing, FAQ, public Planos, and account Planos. LEGAL/404/500 were upgraded in R46.97; Admin/Client in R46.94–R46.98.

## Design direction
- Consistent dark graphite and emerald identity approved for ZVM; direct typography and restrained depth. Avoid decorative glow, ungrounded simulated dashboards, competitor copying, stock images, and large unneeded frontend dependencies.
- Preserve the approved centered hero “Organize o atendimento. Automatize a rotina.” with two purposeful calls to action, a discreet single official Chrome Web Store badge, animated background respecting reduced-motion, and real ZVM UI screenshots.
- Marketing story: Atenda → Organize → Reutilize → Automatize, using concise clear operational descriptions; four true product pillars: contextual conversations, workflows, reusable library, license control.
- FAQ rebuilt as 4 anchored topic areas, preserving the canonical ZVM_FAQ_ITEMS copy and native <details> disclosures. Search is accent-insensitive, local-only, keyboard operable, with an ARIA live-region result count and empty state.
- Public Planos have a narrative purchase journey, consistent cards from the authoritative ZVM_PUBLIC_PLANS catalog, and included capability descriptions. Portal Planos reuse the same purchase journey with shared CSS; historical renewal/checkout contracts remain unchanged.

## Sale-pause invariants
- Production owner flag ZVM_SALES_PAUSED=1 MUST stay enabled. All public/portal paused purchase CTAs and Cakto URLs stay disabled as per R46.99. The new stories and consult links do not reopen sales.
- With ZVM_SALES_PAUSED=0 after explicit owner authorization, anonymous checkout remains possible with official Cakto checkout links. The user is told to use a valid email and link the key to their account later.
- Webhook, paid deliveries, durable mail queue, licenses, auth, admin, private Analytics, migration and IP rules are untouched. External Cakto URLs already distributed are NOT controlled by this site.
