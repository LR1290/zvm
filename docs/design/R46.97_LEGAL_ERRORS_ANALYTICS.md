# ZVM R46.97 - Continuity of legal, recovery and Analytics interfaces

Scope: presentation and accessibility only. Production remains on R46.96 until verification.

## What changes
- Privacy: adds the missing semantic main target used by the skip link; keeps the same nine legal sections and original content, the existing account-aware public nav and the shared public footer. Removes duplicate standalone CSS injection and runtime HTML rewriting for this page.
- Terms: same source of legal copy, locale (pt-BR, pt-PT, en), canonical, hreflang, table of contents and content anchors. Only CSS and body class change.
- Error 404/500: adds main-content landmarks and unified premium visuals; maintains the recovery links and original HTTP status handling.
- Analytics: the existing private dashboard, sources, permissions, exports, metrics, laboratory and purge confirmation are unchanged. Scoped CSS improves contrast and responsive layout without touching request handlers, data, or charts.
- Tokens inherit the R46.96 public stylesheet on legal and error pages. The Analytics component uses its own isolated variables to avoid CSS leaking into Admin/Client.
- New immutable assets: assets/zvm-legal-premium.222751f96dd9.css (SHA-256: 222751f96dd906db2fdce0d10922f2346eea078de6725759da13b6c09c71b3e2); assets/zvm-analytics-premium.75b34337c294.css (SHA-256: 75b34337c2945201a425f61b7b85325e0f3d9d0ca01c140d7de0ae6e46c3ab11).
- Existing CSS assets remain referenced elsewhere. They are not removed until the dependent pages have been migrated and proven safe. The new CSS contains no !important overrides.

## Quality, compliance and commerce boundaries
- Do not rewrite legal representations, policies, translations, dates or company claims without review.
- Do not run real transactions, delete customers, invoke live administrative APIs or test a real login.
- npm run check now includes tests/r46-97-legal-analytics-design.test.js: immutable asset integrity, main landmarks, no redundant CSS, text/locale/canonical, safe analytics fixture and security-sensitive DOM preservation.
- Browser QA includes 21 additional Chromium captures (Privacy, Terms in 3 locales, 404, 500 and Analytics) at 1440, 390 and 320 CSS px, in addition to 39 earlier captures. All are served from an offline synthetic host.
- Any overflow, missing navigation/anchor, JS exception or change to sensitive functionality is a hard blocker. Review screenshots and both Security and Chromium workflows before merge.
- Rollback: redeploy the previous known-good R46.96 revision in Render. No schema or license changes.
- References: W3C WCAG 2.2 https://www.w3.org/WAI/WCAG22/quickref/ and existing R46.94-96 design system docs.
